# Producer art

Place producer images here (webp/avif/jpg/png), e.g. `daniska/portrait.webp`,
then fill the matching slot in `web/public/theme.js`.
Variants: `portrait` (head/shoulders), `seasonalPortrait` (season styling), `fullBody` (3/4 or full body).
Recommended: 3:4 ratio, ~1200x1600, compressed webp/avif under ~300 KB.
